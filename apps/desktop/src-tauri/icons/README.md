# Application icons

The alpha identity uses the same restrained rail/rung mark as the in-app RACK wordmark.

- warm paper background;
- RACK purple structure;
- one moss rung to echo the wider Good Ship product family;
- deliberately simple geometry that remains legible at small desktop-icon sizes.

`scripts/generate-assets.cjs` materialises the committed PNG source and generates the matching Windows ICO during install/CI. Treat the mark as an alpha identity: refine from real use before adding decorative detail or a larger icon system.
